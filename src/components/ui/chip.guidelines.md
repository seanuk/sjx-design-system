## Guidelines

A chip is a small, compact label. It can show a status or tag, or act as a filter.

**Use it** for statuses in tables, tags on items, or quick filters.

| Variant | Use it for |
| --- | --- |
| Default | A plain tag. |
| Variants | Filled for emphasis, outline for lighter tags. |
| Sizes | Match the text size around it. |
| Tones | Colour groups, such as by category. |
| Status | Set meanings: success, warning, error, neutral. |
| With Count | A filter with the number of matching items. |
| With Icon | Adding meaning that doesn't rely on colour. |
| Disabled / Focused | See Shared states. |
| In Context | Example of chips in a real layout. |

**Do**

- Keep the text to one or two words.
- Use the same colour for the same status everywhere.

**Don't**

- Use a chip as a main button.
- Use status colours for plain tags. It confuses meaning.
