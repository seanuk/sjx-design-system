## Guidelines

A radio group lets the user pick exactly one option from a short list.

**Use it** for two to six options the user should see at once. For more than six, use Select. For a yes/no that applies at once, use Switch.

**States:** Default, Focused, Disabled. See Shared states.

**Do**

- Pre-select the safest or most common option where it helps.
- Give the group a label (a legend) that asks the question.
- List options vertically, in a logical order.

**Don't**

- Use a single radio button on its own. Use a Checkbox.
- Use radios for many options. They take up too much space.
- Mix radios and checkboxes in one group.
