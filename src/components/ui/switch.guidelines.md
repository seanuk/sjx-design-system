## Guidelines

A switch turns a setting on or off, and the change happens at once.

**Use it** in settings, where there is no Save button. If the choice is only saved when a form is sent, use Checkbox.

| Variant | Use it for |
| --- | --- |
| Off / On | The two values. |
| Small | Dense areas, such as table rows or compact panels. |
| Disabled / Disabled On | The setting is locked. Say why nearby. |

**Do**

- Label the setting, not the action: "Email alerts", not "Turn on email alerts".
- Show the result at once, or a loading state if it takes time.

**Don't**

- Use a switch inside a form that needs a Submit button.
- Add "On" and "Off" text next to it. The switch shows that already.
