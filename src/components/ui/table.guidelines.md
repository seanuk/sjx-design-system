## Guidelines

A table shows data in rows and columns so users can scan and compare.

**Use it** for structured data with several attributes per item. For a few items with rich content, use Cards.

| Variant | Use it for |
| --- | --- |
| Default | Standard data lists. |
| Density | Compact rows for expert users with lots of data; roomy rows for casual use. |
| With Totals | Sums or averages in a footer row. |
| With Status And Actions | Status Chips and a row menu for actions. |
| Selected Row | Showing which row is chosen, such as for bulk actions. |

**Do**

- Right-align numbers, and use the same decimal places down a column.
- Keep headers short, with units: "Cost (£)".
- Keep the header visible on long tables.

**Don't**

- Use tables for page layout.
- Squeeze many columns onto mobile. Hide or stack less important ones.
