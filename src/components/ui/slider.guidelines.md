## Guidelines

A slider lets the user pick a value, or a range, by dragging along a track.

**Use it** when a rough value is fine and seeing the scale helps, such as volume or a price filter. If the user needs an exact number, use Input.

| Variant | Use it for |
| --- | --- |
| Default | One value. |
| Range | A low and high value, such as £10 to £50. |
| Focused / Disabled | See Shared states. |

**Do**

- Show the current value next to the slider.
- Label the min and max.
- Make sure arrow keys move it, for keyboard users.

**Don't**

- Use it for exact values, such as a date of birth.
- Use it for very wide ranges with fine steps. Dragging becomes fiddly.
