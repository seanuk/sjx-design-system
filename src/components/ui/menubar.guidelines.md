## Guidelines

A menubar is a desktop-style row of menus: File, Edit, View.

**Use it** in tool-like apps with many commands, such as editors. For site navigation, use Navigation Menu. For a few actions, use Dropdown Menu.

**States:** Default, Focused. See Shared states.

**Do**

- Group commands the way desktop apps do, so users find them by habit.
- Show keyboard shortcuts next to commands.
- Support arrow keys between menus.

**Don't**

- Use it on mobile. It needs space and a pointer.
- Put links to other pages in it.
