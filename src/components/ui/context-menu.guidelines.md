## Guidelines

A context menu opens on right-click (or long-press) and shows actions for the thing under the pointer.

**Use it** as a shortcut in rich apps, such as file lists or canvases. It has the same variants as Dropdown Menu: With Icons And Shortcuts, With Submenu, and Selection Items.

**Do**

- Make every action in it reachable another way too. Many users never right-click.
- Show only actions that fit the item clicked.

**Don't**

- Use it as the only way to do something.
- Replace the browser menu on plain text or links.
