## Guidelines

An avatar shows a person or team as a photo or initials.

**Use it** next to names in comments, lists and account menus.

| Variant | Use it for |
| --- | --- |
| Default | A photo. |
| Fallback | Initials when there is no photo, or it fails to load. |
| Sizes | Small in lists, larger on profile pages. |
| With Badge | Showing status, such as online. |
| Group | Several people, such as who is on a project. Overflow shows "+3". |

**Do**

- Give it alt text with the person's name, unless the name is next to it.
- Always show initials if the image fails.

**Don't**

- Use an avatar alone where the name matters. Show the name too.
- Show more than about five in a group.
