## Guidelines

A stat shows one key number, often with its change over a period.

**Use it** for headline figures on dashboards, such as revenue or active users.

| Variant | Use it for |
| --- | --- |
| Default | A number going up, where up is good. |
| Going Down | A number going down, where down is bad. |
| Up Is Bad | Numbers where a rise is bad, such as costs or errors. Colours flip. |
| No Change | No movement. Neutral colour. |
| Value Only | When change doesn't matter. |
| In A Row | Several stats side by side. |

**Do**

- Say what the change compares to: "vs last month".
- Use Up Is Bad where needed, so green always means good.

**Don't**

- Show more than four or five in a row.
- Show a change without its period.
