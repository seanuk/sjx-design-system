## Guidelines

Tabs switch between views of related content in the same place.

**Use it** when content splits into a few parallel groups and users need only one at a time. For steps in order, use a stepper or Questionnaire. For moving between pages, use navigation.

| Variant | Use it for |
| --- | --- |
| Default | Contained tabs, such as inside a card or panel. |
| Line | Page-level tabs with a lighter look. |
| Vertical | Many tabs, or settings pages with a side list. |
| With Icons | When icons help users scan. Keep the text label. |
| Focused | See Shared states. |

**Do**

- Keep labels to one or two words.
- Keep two to six tabs. Beyond that, use a Sidebar or Select.
- Remember the last tab picked, where it helps.

**Don't**

- Make users compare content across tabs. Put it side by side.
- Nest tabs inside tabs.
