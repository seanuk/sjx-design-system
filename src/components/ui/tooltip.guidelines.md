## Guidelines

A tooltip shows a short label when the user hovers over or focuses on an element.

**Use it** to name icon-only buttons, or to add a brief hint. For anything users must read or click, use Popover.

| Variant | Use it for |
| --- | --- |
| Default | Shows on hover or focus. |
| Open | The tip is showing. |
| Sides | Pick the side with the most room. Top is the default. |
| Focused | Shows when reached by keyboard. |

**Do**

- Keep it to a few words.
- Show it on keyboard focus, not only on hover.

**Don't**

- Put links or buttons inside it.
- Hide key information in it. Touch users can't hover.
- Repeat the visible label word for word.
