## Guidelines

A button group joins related buttons into one control.

**Use it** for a set of actions on the same thing, such as text formatting or view options. For unrelated actions, use separate buttons with space between.

| Variant | Use it for |
| --- | --- |
| Default | A row of related actions. |
| Vertical | Narrow spaces, such as a side panel. |
| Sizes | Match the size of nearby buttons. |
| Icon Only | Toolbars with familiar icons, such as bold and italic. |
| With Separator | Splitting sub-groups inside one group. |
| With Text | A label or value shown inside the group, such as a page count. |
| With Input | An input joined to a button, such as search or a quantity stepper. |
| Nested | Groups of groups, such as a full toolbar. |

**Do**

- Keep two to five buttons per group.
- Give every icon-only button an accessible label and a tooltip.

**Don't**

- Put a primary and a destructive action in the same group.
- Use it in place of Tabs to switch views.
