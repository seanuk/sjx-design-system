## Guidelines

A navigation menu is the main set of links across the top of a site. Items can open panels of sub-links.

**Use it** for site-wide navigation on marketing or content sites. For app navigation with many sections, use Sidebar.

**States:** Default, Focused. See Shared states.

**Do**

- Keep top-level items to about seven.
- Show which section the user is in.
- Open panels on click or keyboard, not hover alone.

**Don't**

- Put actions, such as Delete, in it. It is for links.
- Hide key pages inside panels.
