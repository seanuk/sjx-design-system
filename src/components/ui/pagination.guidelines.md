## Guidelines

Pagination splits a long list into pages and lets users move between them.

**Use it** for search results and tables where users may jump to a set place. For feeds people browse, consider "Load more".

| Variant | Use it for |
| --- | --- |
| Default | A few pages, all shown. |
| Many Pages | Long sets. Middle pages fold into "…". |
| Custom Labels | Changing Previous and Next text, such as for translation. |
| Focused | See Shared states. |

**Do**

- Mark the current page clearly.
- Show the total, such as "1 to 20 of 340".

**Don't**

- Hide Previous and Next on small screens.
- Reset the user to page 1 after they change a filter without saying so.
