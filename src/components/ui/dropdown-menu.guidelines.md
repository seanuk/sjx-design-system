## Guidelines

A dropdown menu shows a list of actions or options when the user clicks a trigger.

**Use it** to tuck away secondary actions, such as "More" on a row. For picking a form value, use Select.

| Variant | Use it for |
| --- | --- |
| Default | A short list of actions. |
| With Icons And Shortcuts | Power users, and actions with a known shortcut. |
| With Submenu | A second level, such as "Move to" then a folder. Use sparingly. |
| Checkbox Items | Turning several options on or off, such as visible columns. |
| Radio Items | Picking one option, such as sort order. |
| Inset Items | Lining up items with and without icons or ticks. |
| Open | The menu is showing. |

**Do**

- Start items with a verb.
- Put destructive items last, split off with a separator.

**Don't**

- Hide the main action in a menu.
- Go deeper than one submenu.
