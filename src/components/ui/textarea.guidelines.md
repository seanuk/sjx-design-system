## Guidelines

A textarea takes more than one line of text: a comment, a note, a description.

**Use it** when the answer may run past one sentence. For short answers, use Input.

**States:** Default, Filled, Focused, Error, Disabled. See Shared states.

**Do**

- Size it to the answer you expect. Three to five rows suits most comments.
- Show a character count if there is a limit.
- Pair it with a Label, or wrap it in a Field.

**Don't**

- Use it for one-word or one-line answers.
- Cut the user off at a limit without warning.
