## Guidelines

A select lets the user pick one option from a list that opens on click.

**Use it** for seven or more options, or when space is tight. For six or fewer, Radio Group is faster, as users see every option without a click.

| Variant | Use it for |
| --- | --- |
| Default | No value picked yet. Shows a placeholder. |
| Selected | A value is picked. |
| Small | Dense areas, such as filters or table toolbars. |
| Open | The list is showing. |
| Error / Disabled | See Shared states. |

**Do**

- Sort options in a clear order: alphabetical, by size, or by how often they are used.
- Write a placeholder that prompts: "Choose a country".
- Add search when the list is long (over 15 items).

**Don't**

- Use it for two or three options. Use Radio Group.
- Use it to trigger an action. Use a Button or menu.
- Hide a likely answer deep in a long list.
