## Guidelines

A card groups content about one thing in a box.

**Use it** for items users scan and compare, such as projects or plans, or to set apart a block on a dashboard.

| Variant | Use it for |
| --- | --- |
| Default | Title, description and body. |
| Small | Dense grids or side panels. |
| With Action | An action in the header, such as a menu or "Edit". |
| With Footer | Main actions or summary info at the bottom. |

**Do**

- Keep one topic per card.
- If the whole card is clickable, make it one link and avoid other buttons inside.

**Don't**

- Put cards inside cards.
- Wrap every section of a page in a card. It adds noise.
