## Guidelines

A label names a form control, so users and screen readers know what it is for.

**Use it** with every Input, Textarea, Select, Checkbox, Radio, Switch and Slider.

| Variant | Use it for |
| --- | --- |
| Default | A label on its own, set apart from the control. |
| With Input | A label tied to its input. Clicking the label focuses the input. |

**Do**

- Link the label to its control (htmlFor and id).
- Keep it short. Use a noun: Email, Start date.
- Place it above the control, or to the right of a checkbox or radio.

**Don't**

- Hide the label to save space. Use a visually hidden label if you must.
- End labels with a colon.
- Write instructions in the label. Put them in a hint below.
