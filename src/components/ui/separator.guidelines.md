## Guidelines

A separator is a thin line that splits content into groups.

**Use it** when spacing alone doesn't make the groups clear.

| Variant | Use it for |
| --- | --- |
| Horizontal | Between stacked sections, such as in a menu or card. |
| Vertical | Between items in a row, such as toolbar buttons. |

**Do**

- Try spacing first. Add a line only if groups still blur.
- Mark purely visual lines as decorative, so screen readers skip them.

**Don't**

- Put a line between every item. It adds noise.
- Use it in place of a heading.
