## Guidelines

A checkbox lets the user turn one option on or off, or pick many from a list.

**Use it** when choices are independent, or for a single "I agree". If the user must pick only one, use Radio Group. If the change takes effect at once, use Switch.

| Variant | Use it for |
| --- | --- |
| Unchecked / Checked | The two values. |
| With Label | The standard form. Use this almost every time. |
| Error | A required box is not ticked, such as terms. |
| Disabled / Disabled Checked | The option can't change now. Keep its value visible. |

**Do**

- Make the label clickable, not only the box.
- Write labels as positive statements: "Send me updates".
- List options vertically.

**Don't**

- Use negative labels: "Don't send me updates".
- Pre-tick boxes for marketing consent. UK GDPR requires opt-in.
- Use a checkbox for an instant setting. Use Switch.
