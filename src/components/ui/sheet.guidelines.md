## Guidelines

A sheet slides in from the edge of the screen and holds a task or details.

**Use it** for longer tasks or details where the user may want context from the page behind, such as editing a record or filters.

| Variant | Use it for |
| --- | --- |
| Default | Details or settings from the right edge. |
| Sides | Right for details, left for navigation, bottom for mobile actions. |
| With Form | Editing a record without leaving the list. |

**Do**

- Keep Save and Cancel visible at the bottom.
- Close it on Escape, and warn if changes are unsaved.

**Don't**

- Open a sheet from inside a sheet.
- Use it for a quick yes or no. Use Dialog.
