## Guidelines

An alert is a message on the page that tells users something important about the current view.

**Use it** for messages that should stay until fixed or read, such as a failed payment. For brief confirmations, a toast is lighter.

| Variant | Use it for |
| --- | --- |
| Default | Neutral information. |
| Variants | Match the tone to the message: info, success, warning, error. |
| With Action | When the user can fix it now, such as "Update card". |
| Without Icon | Tight spaces. Keep the colour and title clear. |

**Do**

- Lead with what happened, then what to do.
- Place it near the thing it is about.

**Don't**

- Show several alerts at once. Merge them.
- Rely on colour alone to show the tone.
- Use error styling for things that aren't errors.
