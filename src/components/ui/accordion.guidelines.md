## Guidelines

An accordion stacks headings that open to show content below.

**Use it** when users need only some sections, such as FAQs. If most users need all the content, show it openly.

| Variant | Use it for |
| --- | --- |
| Default | One section open at a time. |
| Multiple | Several sections open at once, for comparing. |
| Focused | See Shared states. |

**Do**

- Write headings that tell users what's inside.
- Use an icon that shows open and closed state.

**Don't**

- Hide key steps or errors inside a closed section.
- Nest accordions inside accordions.
