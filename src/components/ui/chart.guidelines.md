## Guidelines

A chart shows the shape of numbers: a trend, a comparison or a share.

**Use it** when the pattern matters more than exact values. For exact values, use Table or Stat.

| Variant | Use it for |
| --- | --- |
| Bar Single Series | Comparing one measure across categories. |
| Bar Grouped | Comparing two or three series in each category. |
| Bar Stacked | Showing parts that add up to a total. |
| Line With End Labels | Trends over time. Labels at the line ends replace a legend. |
| Area Single Series | One trend over time where volume matters. |
| With Table | Giving exact values, and an accessible version, under the chart. |

**Do**

- Write a title that states the finding: "Sign-ups doubled in March".
- Start bar charts at zero.
- Label axes with units.

**Don't**

- Use colour alone to tell series apart.
- Use pie charts or 3D effects.
- Show more than about five series in one chart.
