## Guidelines

A questionnaire asks the user questions with set choices, one step at a time.

> This is a custom component. Its description here is based on its story names; check it against the design.

**Use it** for guided flows, such as onboarding or short surveys. For a standard form, use Field and its controls.

| Variant | Use it for |
| --- | --- |
| Default | The standard flow. |
| Keyboard Shortcuts | Picking answers with number keys, for speed. |
| Disabled Choice | An option that doesn't apply. Say why. |
| In Card | Embedding in a page. |
| In Dialog | A short flow over the current page. |

**Do**

- Show progress, such as "2 of 5".
- Let users go back and change answers.
- Keep each question to one idea.

**Don't**

- Ask questions you don't use.
- Put long flows in a Dialog.
