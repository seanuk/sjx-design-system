## Guidelines

A breadcrumb shows where the user is in a hierarchy and lets them step back up.

**Use it** on pages three or more levels deep. Skip it on flat sites or the home page.

| Variant | Use it for |
| --- | --- |
| Default | Short paths that fit on one line. |
| Collapsed | Long paths. Middle levels fold into "…". |
| Focused | See Shared states. |

**Do**

- Make every item a link except the current page.
- Use the same page names as the headings they lead to.

**Don't**

- Use it as the main navigation.
- Show the user's click history. It shows structure, not history.
