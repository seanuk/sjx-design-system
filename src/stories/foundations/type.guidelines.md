## Guidelines

All type is set in Figtree. Sizes are shown as font size / line height, in pixels.

| Style | Sizes | Weight | Use for |
| --- | --- | --- | --- |
| heading | xl 32/40, lg 20/24, md 16/24, sm 14/24 | Bold | Page titles (xl), section titles (lg), card and panel titles (md, sm). |
| body | lg 16/24, md 14/24, sm 12/24 | Regular | Running text. md is the default. |
| button | lg 16/24, md 14/24, sm 12/24 | Medium, uppercase, 1px tracking | Button labels only. |
| link | lg 16/24, md 14/24, sm 12/24 | Regular, underlined | Links in text. Match the size of the text around it. |
| label | lg 16/16, md 14/16, sm 12/16, xs 10/16 | Regular | Form labels, Chips, table headers and other short UI text. |

**Do**

- Use one heading-xl per page.
- Keep headings in order. Don't skip from xl to sm.
- Keep lines of body text to about 60 to 80 characters.

**Don't**

- Use button styles for anything but buttons. Uppercase is hard to read in long runs.
- Use label-xs (10px) for anything people must read. It is very small; keep it for counts or badges.
- Remove the underline from links in text.
