## Guidelines

Shadows lift an element above the page. Higher means more temporary.

| Token | Use for |
| --- | --- |
| shadow-sm | Cards and items that sit on the page. |
| shadow-md | Menus, Popovers, Select lists, Tooltips. |
| shadow-lg | Dialogs and Sheets. |
| focus ring / primary | Keyboard focus on any control. |
| focus ring / error | Keyboard focus on a control in its error state. |

**Do**

- Raise things that float over other content.
- Show a focus ring on every interactive element.

**Don't**

- Use shadows for decoration.
- Stack shadow-lg items on top of each other.
