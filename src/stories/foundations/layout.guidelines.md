## Guidelines

Breakpoints set where layouts change. Each one is a minimum width.

| Breakpoint | Min width |
| --- | --- |
| watch | 160px |
| mobile-sm | 320px |
| mobile | 400px |
| tablet | 768px |
| desktop-sm | 1024px |
| desktop-md | 1280px |
| desktop | 1440px |
| tv | 1920px |

**Do**

- Design mobile first, then add space as screens grow.
- Test at 320px. It is the narrowest common phone width.

**Don't**

- Design a layout for every breakpoint. Most pages need three: mobile, tablet, desktop.
- Let pages scroll sideways at any width.
